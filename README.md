# Тестирование класса BooksCollector


В рамках разработки реализованы следующие тесты для проверки функциональности класса `BooksCollector`:


1. `test_add_new_book_add_two_books` — проверка успешного добавления двух книг в коллекцию: после добавления двух книг длина словаря `books_genre` должна быть равна 2.


2. `test_add_new_book_long_name` — проверка ограничения на длину названия книги: книга с названием длиннее 40 символов не должна добавляться в коллекцию.


3. `test_add_new_book_duplicate` — проверка защиты от дублирования: попытка повторно добавить книгу с тем же названием не должна приводить к появлению дубликата в коллекции (длина `books_genre` остаётся прежней).

4. `test_set_book_genre_valid_genre` — параметризованный тест для проверки корректной установки РАЗРЕШЁННЫХ жанров для существующей книги. Использует `@pytest.mark.parametrize` для проверки нескольких допустимых жанров в одном тесте (проверяемые жанры: «Фантастика», «Ужасы», «Детективы», «Мультфильмы», «Комедии»). После вызова `set_book_genre` метод `get_book_genre` должен возвращать установленный жанр.


5. `test_set_book_genre_nonexistent_book` — проверка обработки попытки установить жанр для несуществующей книги: такая книга не должна появляться в `books_genre`.


6. `test_set_book_genre_invalid_genre` — проверка обработки недопустимого жанра: если жанр не входит в список разрешённых, метод `get_book_genre` должен возвращать пустую строку (`''`).


7. `test_get_book_genre_existing_book` — проверка получения жанра для книги с установленным жанром: метод `get_book_genre` возвращает значение, ранее установленное через `set_book_genre`.


8. `test_get_book_genre_nonexistent_book` — проверка запроса жанра для несуществующей книги: метод `get_book_genre` возвращает `None`.

9. `test_get_books_with_specific_genre_existing` — проверка фильтрации книг по существующему жанру: метод `get_books_with_specific_genre` возвращает точный список книг заданного жанра.


10. `test_get_books_with_specific_genre_nonexistent` — проверка запроса по несуществующему жанру: метод `get_books_with_specific_genre` возвращает пустой список (`[]`).


11. `test_get_books_for_children` — проверка фильтрации книг для детской аудитории: метод `get_books_for_children` возвращает только книги с жанрами без возрастного ограничения (например, «Мультфильмы», «Комедии»), исключая «взрослые» жанры (например, «Детективы»).


12. `test_add_book_in_favorites_nonexistent_book` — проверка невозможности добавления в избранное книги, отсутствующей в коллекции: книга не должна попадать в список избранного (`favorites`), если её нет в `books_genre`.

13. `test_add_delete_book_in_favorites` — проверка полного цикла работы с избранным: книга успешно добавляется в избранное, а после вызова `delete_book_from_favorites` исчезает из списка `favorites`.

14. `test_get_list_of_favorites_books` — проверка корректности получения полного списка избранного: метод `get_list_of_favorites_books` возвращает точный перечень всех книг, ранее добавленных в избранное, без лишних записей.


---

## Запуск тестов

Для запуска тестов из терминала используйте команду:

pytest -v tests.py
